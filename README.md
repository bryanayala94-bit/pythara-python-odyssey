# PYTHARA • Python Odyssey

**Master Python through epic storytelling, 3D adventures, and seamless coding challenges.**

A neuroscience-optimized video game that teaches real Python so effectively you'll become a master without realizing you're learning.

## Play on iPhone (Recommended)

1. Open this repo in Safari on your iPhone
2. Tap the **Code** button (top right) → **Download ZIP**
3. Unzip the file in the Files app
4. Open `index.html` in Safari
5. Tap the Share button → **Add to Home Screen**

It installs as a full-screen app with the purple snake icon. Works offline after first load!

## Features
- 3D hub world with Three.js
- 4 complete chapters with real Python challenges (variables → classes)
- Live Python execution via Pyodide (no backend needed)
- The Forge: full creator mode with project memory
- Eternal Codex with runnable examples
- Spaced repetition, active recall, dual coding — all proven retention techniques
- Progress saves automatically

## For Experts
All code is 100% correct, modern Python 3.12+. Beginners see only the story and 'magic runes'.
